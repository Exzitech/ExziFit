# Notes de travail (mémoire de Claude)

Copie des notes que Claude garde d'une session à l'autre sur ExziFit. Elles vivent
normalement **hors du dépôt**, dans le dossier de mémoire du poste :

```
<profil>\.claude\projects\c--Users-tomro-Desktop-ExziFit\memory\
```

(le nom du dossier dérive du chemin du projet : adapter si le dépôt est cloné ailleurs).

## Remettre en place sur une nouvelle machine

Copier tous les `.md` de ce dossier, `README.md` excepté, vers le chemin ci-dessus.
`MEMORY.md` est l'index chargé à chaque session.

Ce sont des préférences de travail, pas de la doc : en cas de contradiction, la doc fait foi.
